Understand Sitting Height-to-Arm Span Ratio +

This ratio compares seated trunk height with arm span. It describes two linear measurements using a common unit.

Calculation method

Sitting-height-to-arm-span ratio = sitting height ÷ arm span. Matching length units cancel; multiplying by 100 gives a percentage.

Measurement protocol

Measure sitting height with a defined seat and head position. Measure arm span with arms extended horizontally and a consistent endpoint protocol.

Interpretation and limits

The ratio is sensitive to posture, arm extension and landmark selection. It is not a diagnostic proportion; use an age- and population-specific reference if a formal assessment calls for one.
