Understand Fat Mass Index (FMI) +

Fat Mass Index scales an assessment-reported fat mass to height. Unlike BMI, it separates fat mass from other body components when the input method supports that distinction.

Calculation method

FMI = fat mass in kilograms ÷ height in metres². The result is expressed in kg/m².

Measurement protocol

Use fat mass from a body-composition report and height measured with a reliable protocol. Make sure the report’s units and definition are clear before conversion.

Interpretation and limits

FMI inherits the source method’s error and needs population-matched reference values for classification. It is descriptive; this calculator does not set a healthy range or diagnose a condition.
