Understand Biacromial Width Ratio Calculator +

This measure compares biacromial breadth—the distance between the shoulder acromion landmarks—with standing height.

Calculation method

Biacromial breadth-to-height ratio = biacromial breadth ÷ height after both measurements use the same unit. The result has no physical unit.

Measurement protocol

Use an anthropometric breadth caliper and trained landmarking for the shoulder points. A tape measure around the shoulders is not an equivalent breadth measurement.

Interpretation and limits

The value is descriptive and protocol-sensitive. It is not a measure of shoulder circumference, skeletal maturity or health, and there is no universal clinical cutoff.
