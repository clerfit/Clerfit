Understand Anthropometric Z-Score +

A z-score expresses how far an observed measurement is from a reference mean in units of that reference standard deviation.

Calculation method

z = (observed value − reference mean) ÷ reference standard deviation. The standard deviation must be positive and all three values must share the same unit.

Measurement protocol

Choose reference data that match the measurement site, age, sex, population and method. Enter values in one unit and use the same reference distribution for comparisons.

Interpretation and limits

A z-score is only as appropriate as its reference dataset. This general arithmetic tool does not supply growth charts, population norms or diagnostic cutoffs; a standard score is not a diagnosis.
