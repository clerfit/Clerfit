Understand Sitting Height Ratio +

Sitting-height ratio compares seated height with standing height to describe the proportion of stature above the seated surface.

Calculation method

Sitting-height ratio = sitting height ÷ standing height. Since both are lengths, use matching units; the ratio has no unit.

Measurement protocol

Measure sitting height on a firm, level seat with standardized head and trunk posture, then measure standing height under the same protocol.

Interpretation and limits

The result depends on posture, seat compression and age-related changes. It has no universal diagnostic threshold; use a population-specific reference when formal interpretation is needed.
