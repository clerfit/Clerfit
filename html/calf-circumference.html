Leave segment length blank if you only need the circle-equivalent cross-sectional area.

Method and limitations

For circumference C, diameter = C ÷ π, radius = C ÷ (2π), and circle-equivalent area = C² ÷ (4π). If segment length L is entered, the cylindrical volume proxy is area × L.

The optional volume assumes a constant circular cross-section along the entire segment. Real calf shape and tissue distribution vary; the output is not muscle volume, body composition, or a clinical assessment.

How to use it

Measure at the largest calf girth with the same posture, side and tape tension each time. Segment length is optional and is used only for the simplified cylinder-volume calculation.
