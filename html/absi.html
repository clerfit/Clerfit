ABSI (A Body Shape Index)

What is ABSI?

ABSI combines waist circumference with BMI and height to describe body shape. Its raw value should not be interpreted as an individual health-risk category without an appropriate reference model.

Definition

ABSI (A Body Shape Index) is a metric that assesses body shape using waist circumference, height, and weight. It is used in research to describe body shape in relation to height and weight; a raw value alone is not an individual risk assessment.

Applications

  • Evaluates abdominal fat independent of BMI
  • Helps identify risk of cardiovascular disease
  • Used in obesity and metabolic health assessments
  • Supports personalized diet and fitness programs
  • Monitors changes in body composition over time
  • Used in selected population research with appropriate reference models
  • Integrated in health and fitness tracking tools

Interpreting ABSI

ABSI values should be interpreted using an appropriate published reference model, commonly involving age- and sex-standardized values. This page deliberately reports the raw index only and does not infer an individual risk category.

What does the result mean?

Interpret the ABSI result in the context of the input values, displayed units and assumptions. Measurement error and the assumptions of the selected equation can materially affect the result. It is not a medical diagnosis.

Calculation methodABSI = waist circumference ÷ (BMI^(2/3) × height^(1/2)), using compatible canonical units.

ABSI is a statistical index; risk interpretation requires an appropriate reference and should not be treated as a diagnosis.
