Understand Leg-to-Height Ratio +

This measure expresses a defined leg-length measurement as a fraction of standing height.

Calculation method

Leg-to-height ratio = measured leg length ÷ standing height after matching the units. The result is dimensionless.

Measurement protocol

Choose and document the leg-length landmarks before measuring; different segment-length protocols produce different values. Measure standing height using a consistent posture.

Interpretation and limits

No universal clinical cutoff is supplied. The result is descriptive and should only be compared with values collected by the same method and an appropriate reference population.
