Understand Chest-to-Height Ratio Calculator +

Chest-to-height ratio expresses chest circumference relative to standing height. Both values are lengths, so the calculator first needs compatible units.

Calculation method

Ratio = chest circumference ÷ height using a shared unit. The result is unitless; multiplying by 100 expresses the same proportion as a percentage.

Measurement protocol

Measure chest at a defined breathing phase and height with a standard stadiometer or repeatable method. Convert or select one unit for both measurements.

Interpretation and limits

This is a descriptive proportion, not a screening score. No clinical cutoff is established here, and chest expansion, posture and height measurement error influence the result.
