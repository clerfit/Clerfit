Understand Shoulder-to-Chest Ratio +

This ratio compares shoulder circumference with chest circumference. It is intended for consistent anthropometric tracking rather than classification.

Calculation method

Shoulder-to-chest ratio = shoulder circumference ÷ chest circumference, with both measurements in the same unit.

Measurement protocol

Record the tape path and posture used for both circumferences; chest size varies with breathing and shoulder placement. Repeat using the same procedure.

Interpretation and limits

No universal reference band is provided. The result should not be labeled as an ideal physique or health score; it is sensitive to landmarks and tape technique.
