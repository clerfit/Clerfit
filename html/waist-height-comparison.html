Understand Waist-to-Height Comparison +

This comparison computes waist-to-height ratio for two people and shows the difference between the two ratios. It does not classify either result.

Calculation method

For each person, waist-to-height ratio = waist circumference ÷ height using matching units. Difference = Person B ratio − Person A ratio.

Measurement protocol

Use the same waist landmark and height protocol for both records. Enter all four values in the common unit requested by the calculator.

Interpretation and limits

Waist-to-height ratio can be used as a screening measure in specific adult guidance, but thresholds and applicability depend on age and population. This comparison is not a diagnosis or individualized risk estimate.
