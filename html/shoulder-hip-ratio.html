Understand Shoulder-to-Hip Ratio Calculator +

This tool compares shoulder circumference with hip circumference. It describes relative measurements and does not predict a body type or health outcome.

Calculation method

Shoulder-to-hip ratio = shoulder circumference ÷ hip circumference. Equal length units cancel, leaving a unitless ratio.

Measurement protocol

Use a consistent tape path for both sites and record the same posture and conditions. Repeat measurements using the same landmarks before drawing conclusions from small changes.

Interpretation and limits

No validated universal cutoff is supplied. The ratio is sensitive to site definition and tape placement and should not be interpreted as an individual health assessment.
