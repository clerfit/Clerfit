# ClerFit R3 — Input Validation and Unit-System Report

Audit date: 2026-10-16

## Implemented

- `js/input-validation.js` is loaded on interactive calculator pages. It rejects non-finite numeric inputs and values outside the field's HTML and semantic bounds; errors use `role="alert"` and `aria-invalid`, with focus/scroll-to-field behavior.
- 238 static numeric fields have `min`, `max`, and `step` attributes. `INPUT_BOUNDARY_VERIFIED.csv` is regenerated by `tests/verify.js`. Runtime-generated inputs are tested only where covered by interaction tests; exhaustive semantic edge-case testing is not claimed.
- The US Navy body-fat equation validates entered measurements and converts centimetres to inches before applying inch-based logarithmic constants.
- Teen BMI avoids adult categories and states that age- and sex-specific growth-chart interpretation is required; no pediatric percentile is fabricated.
- Heath–Carter mesomorphy uses arm and calf girths corrected by the corresponding skinfolds.
- `js/unit-system.js` provides unit conversion inside applicable calculators. There is no global unit-preference toggle and no localStorage/sessionStorage persistence.
- Length/distance conversion is supported across compatible units; incompatible dimensions such as kg to km return `NaN`.

## Verification

- `node tests/verify.js`: PASS — route vectors, static bounds, conversion guards and interpretation safeguards.
- `node tests/unit-conversion-property.test.js`: PASS — 9 known answers, 6 round trips, incompatible dimensions and non-finite inputs.
- `node tests/contact-form.test.js`: PASS for mocked handler behavior only; live delivery is not established by this test.
